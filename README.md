## Publishing

The `Publish Helm chart` workflow publishes the chart as an OCI artifact at
`oci://ghcr.io/<repository-owner>/karpenter-crd`.
It requires the `name` in `Chart.yaml` to be lowercase, as required by OCI
registries.

- Pushing a tag publishes a chart whose version is the tag name with an optional
  leading `v` removed. Tags must therefore be valid Helm chart versions.
- Run the workflow manually to publish a `develop` or `temporary` prerelease
  from any ref. Leave **ref** empty to package the selected workflow revision,
  and leave **chart_version** empty to create a unique version. Alternatively,
  provide a valid Helm chart version explicitly.
